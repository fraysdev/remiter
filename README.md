# Remiter
A simple floating timer desktop application.

## Features
While the app is usable, not all features has been implemented. I have some plan to extend the features of the application while also adding more advance features.

- [X] **Timer**  
      A countdown from certain duration until ends at 00:00.
  - [X] Extended timer
  - [X] Presets
- [X] **Stopwatch**  
      Measuring time from start (active) to end (deactive)
- [ ] **Alarm**  
      Same as timer, but instead target time instead of duration.
- [ ] **Schedule**  
      Advanced sequence of timers. Can be use as Podomoro Timer too.

## Installing
This application is in very early stage, so no binary files available. You need to compile it yourself.
